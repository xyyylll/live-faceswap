# faces/

单图换脸的源脸照片放在这里，在界面里点 **Select a face** 选择。

## 本目录的照片
`source_01.jpg` ~ `source_03.jpg` 是 AI 生成的虚拟人像，仅用于测试换脸效果。

## 只放这两类照片
- AI 生成的、现实中不存在的人；生成时提示词里不要写真人名字或“像某某”。
- 本人书面授权、且已成年的真人。

不要使用从网上找到的真人、网红或明星照片。

## 照片要求
| 项 | 要求 |
|---|---|
| 人数 | 只有一张脸 |
| 角度 | 正脸；偏航、俯仰 ≤15°，侧倾 ≤10° |
| 遮挡 | 无刘海遮眉、无眼镜、无手挡脸 |
| 清晰度 | 脸宽 ≥256px 最好；模型提取身份特征时会缩放到 112×112，脸宽 160px 左右也能用 |
| 光线 | 均匀柔光 |

照片只决定五官和脸型。妆容、肤色和光线主要沿用摄像头画面，头发也不会被替换。

## 检查照片
```bash
Deep-Live-Cam/venv/bin/python tools/check_faces.py faces --sheet faces_sheet.jpg
```
